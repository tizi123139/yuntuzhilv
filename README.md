# 云途智旅

## 📖 项目简介

智能旅游行程规划系统分为**游客前端**与**后台管理端**，面向旅游出行用户与平台管理员。系统融合 **RAG 向量检索 + 云端大模型** 实现 AI 个性化行程规划。

游客登录后可浏览目的地、景点、酒店资源，填写出行时间、预算、旅游偏好等需求；系统对景点、酒店资源进行向量化存储，基于语义相似度匹配符合用户喜好的旅游资源，调用阿里云百炼大模型自动生成结构化旅游行程方案。

管理端提供景点、酒店信息维护、分页查询、资源上下架、图片上传、系统日志管理等功能，实现旅游资源统一管控。系统采用 JWT 实现接口鉴权，区分普通用户与管理员角色，未登录用户无法使用系统核心功能。

后端基于 SpringBoot 开发，业务数据存储于 MySQL，线上部署采用阿里云百炼大模型 API，无需本地部署 Ollama，方便服务器部署上线。

## ✨ 核心功能

### 用户端

1. 用户注册、登录、权限鉴权
2. 热门目的地、景点、酒店信息浏览查询
3. 个人旅游偏好、预算设置
4. **AI 智能行程规划（RAG 语义匹配 + 大模型生成行程）**
5. 行程查看、保存管理

### 管理端

1. 管理员账号登录
2. 景点信息 CRUD、图片上传管理
3. 酒店信息 CRUD、分页管理
4. 旅游资源上下架控制
5. 系统操作日志查看

## 🛠 技术栈

### 后端

- 框架：SpringBoot 3.x
- 数据库：MySQL 8.0
- 安全认证：SpringSecurity + JWT
- AI 服务：阿里云百炼大模型 API、Embedding 向量模型
- 接口文档：Knife4j（OpenAPI3）

### 前端

- 框架：Vue3 

## 🚀 部署说明

1. 环境准备：JDK17 + MySQL8.0 + Maven
2. 创建数据库，执行项目内 SQL 脚本
3. 修改 application.yml 数据库连接、JWT 密钥、阿里云百炼 API 密钥配置
4. 启动后端项目
5. 接口文档访问地址：`http://localhost:8080/api/doc.html`

## 📌 项目特点

1. 采用 RAG 检索增强生成，依托业务库真实景点、酒店数据生成行程，不依赖大模型内部知识库；
2. 语义匹配用户旅游偏好，突破固定标签限制，提升行程推荐精准度；
3. 使用云端大模型 API，适配服务器部署，无需本地运行大模型；
4. 完善权限控制，区分游客、管理员角色；
5. 提供后台管理模块，支持旅游资源持续维护。
